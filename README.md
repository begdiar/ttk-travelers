# ТТК бара Travelers

Справочник технологических карт для бариста Tashkent Travelers Coffee.

Сайт: https://begdiar.github.io/ttk-travelers/

Рецепты зашифрованы паролем (AES-256-GCM, ключ из пароля через PBKDF2 на 600 000 итераций). Без пароля данные не читаются. Пароль спросите у старшего бариста.
